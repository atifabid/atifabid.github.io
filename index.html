Core Technical & Research Projects

  • Spot-Sumo — Sim-to-Real Quadruped Locomotion [Repo] ROS2 Sim-to-Real RL
    Architecting a complete sim-to-real reinforcement learning pipeline for a custom Spot-Sumo quadruped. Integrating ROS2 and Gazebo to simulate complex environment interactions and optimize dynamic gait stability for physical hardware deployment.
  • Lite3 (Deep Robotics) — MuJoCo Implementation [Notes/Demo] MuJoCo Quadruped Autonomy
    Developed a MuJoCo-based simulation environment for the Deep Robotics Lite3 quadruped, addressing a missing architecture gap in official repositories. Tuned physics and contact parameters to ensure accurate sim-to-sim validation for locomotion control policies.
  • Unitree G1 Humanoid — Multi-Agent "Thriller" Simulation [Repo] Kinematics LSTM MuJoCo
    Engineered a local MuJoCo pipeline interfacing with complex humanoid kinematics and pre-trained LSTM policies. Scaled the architecture to batched multi-agent inference, deploying 3 independent G1 humanoids to perform a synchronized dance routine, validating simulation scaling.
  • Prompt2CAD — Neuro-Symbolic Generative Design [Repo] LLM Generative CAD
    Text-to-CAD pipeline that translates natural language into executable SolidWorks geometric feature trees, guaranteeing 100% geometric validity. Bridges LLM reasoning with strict physical and manufacturing constraints.
  • Edge AI Safety Node — Perception & Diagnostics [Demo] ESP32 YOLO SUQ-3
    Architected a low-latency safety perception node (virtual bumper) on constrained ESP32 hardware. Engineered a 3-stage compression pipeline (SUQ-3) to deploy YOLO-based computer vision diagnostics directly onto edge silicon.
  • Local LLM Inference Benchmarks [Code] Benchmarking Hardware Opt.
    Rigorous benchmarking of local inference frameworks (vLLM, Ollama, TensorRT-LLM) for models like Llama 3 and Qwen on consumer GPU architectures, identifying optimal deployment setups for localized robotic reasoning layers.
